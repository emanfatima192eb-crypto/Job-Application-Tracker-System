# Job Application Tracker System

A JavaScript-based project designed to manage and track job applications.

## Features
- Add new job applications
- Update application status
- Delete applications
- Search applications by company or position
- Filter applications by status and salary
- Sort applications by date and salary
- View application statistics
- Undo and Redo actions
- Activity History
- Pagination
- Save application data using LocalStorage

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Purpose
This project helps users organize and manage their job applications in one place.
